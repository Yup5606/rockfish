# 🌧 Rockfish Weatherwear Redesign

## Overview

Rockfish Weatherwear의 브랜드 정체성을 강화하고
사용자 경험을 개선하기 위해 진행한 웹사이트 리디자인 프로젝트입니다.

기존 사이트가 상품 중심으로 구성되어 브랜드 스토리 전달이 부족하다고 판단하여
브랜드 경험 중심의 구조로 재설계하였습니다.
